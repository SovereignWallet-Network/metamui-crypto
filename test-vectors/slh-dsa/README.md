# SLH-DSA Conformance Dataset

This directory is the single source for SLH-DSA conformance vectors used across language implementations.

## Layout

- `official/slh_dsa_acvp_like_vectors.json`
  - ACVP-like JSON generated by Rust canonical implementation.
  - Covers key generation, signature generation, and signature verification groups for all 6 SHAKE parameter sets.
- `portable/slh_dsa_portable_vectors.json`
  - Deterministic portable vectors for cross-language regression and interop checks.
  - Contains fixed-seed keypairs/signatures for all 6 SHAKE parameter sets.

## Generation

From `metamui-crypto-rust`:

```bash
cargo run -p metamui-slhdsa --example generate_slh_dsa_test_vectors -- 1 \
  > ../test-vectors/slhdsa-conformance/official/slh_dsa_acvp_like_vectors.json

cargo run -p metamui-slhdsa --example generate_portable_slh_dsa_vectors \
  > ../test-vectors/slhdsa-conformance/portable/slh_dsa_portable_vectors.json
```

## Consumer Contract

- Implementations must treat these files as immutable test inputs in CI.
- Parameter set labels are canonical:
  - `SLH-DSA-SHAKE-128s`
  - `SLH-DSA-SHAKE-128f`
  - `SLH-DSA-SHAKE-192s`
  - `SLH-DSA-SHAKE-192f`
  - `SLH-DSA-SHAKE-256s`
  - `SLH-DSA-SHAKE-256f`
